# Add Web Album List Root Selection

This spec adds source-or-scratch root selection to the read-only album list
operation exposed by `web serve`, while preserving source-root defaults and the
standalone CLI contract.

Scope: **web album-list adapters, focused tests, collection requests, generated
GraphQL SDL, and related docs only.**
